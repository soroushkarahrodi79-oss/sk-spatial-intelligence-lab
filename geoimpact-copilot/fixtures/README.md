# Synthetic fixture provenance

SPDX-License-Identifier: CC0-1.0

These V5-shaped reports are hand-authored, fictional contract fixtures. They do not contain research observations, third-party data, or results from a GeoImpact-CI run. Dataset names, feature IDs, metric values, geometries, hashes, and engine strings are invented solely to exercise schema validation and deterministic Q&A. Do not cite them as scientific findings.

All original fixture files in this directory are dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode). No external dataset or copied GeoImpact-CI fixture is included. The external contract is referenced by URL in `../source-records.json` and was read-only inspected.

The repeated-looking SHA-256 strings and `synthetic-fixture` engine values are illustrative values, not verifiable input-byte provenance. The prototype reports them as values present in a clearly labelled synthetic example; it does not claim they identify retained inputs.
