# GeoAI architecture roadmap

**Status:** GeoAI-1 is the deployed static catalog; GeoAI-3 has a local deterministic V0.1 prototype; later stages are planned. The public Space is still static HTML and does not run an AI, GIS agent, Earth observation model, hosted model, or backend.

## Current foundation — GeoAI-1

Maintain a static scientific portfolio and project catalog. Keep each research project in its own repository and link to its evidence, methods, releases, and stated limitations. The lab site records project status and does not imply that a demo is a validated result.

## Proposed stages

| Stage | Capability | Evidence and release gate |
| --- | --- | --- |
| **GeoAI-1** | Static scientific portfolio and project catalog | Curated project records, provenance links, status, scope, and publication review. This is the current lab website only. |
| **GeoAI-2** | Evidence-grounded RAG over verified project documentation | Versioned corpus with source IDs and document hashes; answers cite retrievable passages; abstain when evidence is missing or conflicting. No geometry or measured result may be generated by the model. |
| **GeoAI-3** | GeoImpact Evidence Copilot | V0.1 is a local deterministic report parser and evidence-linked Q&A prototype for GeoImpact-CI V4/V5 JSON. It has no operating LLM, hosted backend, web UI, or mutation tools. The roadmap's release gates still require broader independent evaluation before a hosted explanation service. |
| **GeoAI-4** | Spatial queries and controlled geoprocessing | Deterministic operations using GeoPandas, Shapely, PostGIS, or an equivalent selected for the workload. Define CRS, units, geometry validity, input bounds, and reproducible parameters. |
| **GeoAI-5** | Earth observation with STAC and Sentinel imagery | Record product, acquisition time, processing chain, licenses, masks, spatial resolution, and independent reference data. Publish model limits and error metrics; do not claim flood extent without validation. |
| **GeoAI-6** | LLM and spatial-agent evaluation | Benchmark citation fidelity, abstention, tool safety, spatial accuracy, uncertainty calibration, reproducibility, and prompt-injection resistance. Preserve test fixtures and evaluation versions. |
| **GeoAI-7** | Publication-grade research outputs | Reproducible experiments, benchmark reports, model cards, dataset cards, provenance manifests, and publication-ready figures with independent review. |

## Target architecture when justified

1. **Static public frontend:** project catalog and carefully bounded explanations. No private keys or direct privileged APIs.
2. **Authenticated application backend:** identity, request limits, secret storage, schema validation, audit logs, and explicit separation of user requests from tool results.
3. **Verified evidence layer:** versioned documents and deterministic JSON artifacts, indexed with source IDs and retrievable citation spans.
4. **Spatial service:** typed, allowlisted, read-only operations. Deterministic libraries perform all authoritative calculations; the LLM cannot write arbitrary SQL, Python, or files.
5. **Evaluation and provenance:** inputs, source versions, tool versions, parameters, output hashes, uncertainty, and review status captured for each released conclusion.

Do not add a backend, database, vector store, paid model API, or autonomous agent until a measured research need justifies it. Keep each future stage independently deployable and reversible.

## Scientific integrity gates

Every conclusion must expose its provenance, geographic scope, temporal scope, uncertainty, and interpretation limits. Distinguish measured observations from model-generated text. LLMs must never invent geometries, distances, source observations, confidence values, or analytical results. Numerical and spatial claims must be reproducible from deterministic inputs and independently checkable.

The deterministic local GeoImpact Evidence Copilot V0.1 now provides a first implementation of report parsing and evidence-linked Q&A. A hosted LLM explanation service remains proposed until an independently evaluated implementation passes the security, accuracy, provenance, and uncertainty gates above.

## GeoAI-3 prototype status — 2026-10-24

The repository now contains a locally testable V0.1 deterministic prototype under `geoimpact-copilot/`. It validates the current public V4/V5 report shapes, answers only bounded report questions, attaches JSON Pointer or named source-record references to every claim, gates numerical claims against referenced values, and abstains on missing or unsupported evidence. Synthetic fixtures are labeled as non-research examples. The static Hugging Face Space remains the published portfolio and does not expose this prototype.

This milestone does not implement an LLM. `server/explanation-boundary.mjs` is an optional server-side interface for a future provider; V0.1 has no provider client or model credentials. It can only reorder all deterministic, pre-authorized claims, and the server renders the text and numbers. See [GeoImpact Evidence Copilot V0.1](geoimpact-evidence-copilot-v0.1.md) for test results, risks, limitations, and the next release gate.
